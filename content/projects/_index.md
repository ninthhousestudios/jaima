## libaditya

[libaditya](https://gitlab.com/j0sh4rp3/libaditya)

libaditya is an astrological calculation library written in Python. My hope is that
astrologers who want a deeper understanding of the calculations, and more control over
there calculations, or who want to do research, can benefit from this software by being
able to program in a language that resembles astrology.

I have designed the library so that it resembles astrological language, thus helping
astrologers who may not know how to program to more easily to do so in order to be able
to think astrologically rather than programmatically.

At this point libaditya is on indefinite hiatus. There is a solid foundation. I am
actually using this foundation for a different project, which unfortunately is not open
source (though I hope that one day it will be), and which unfortunately I can't talk
much about right now, though hopefully soon I will be able to.
